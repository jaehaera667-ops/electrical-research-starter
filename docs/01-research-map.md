## 推荐的新手起点

如果你的目标是先完整体验一次科研，而不是立刻进硬件实验室，优先考虑：

1. **电力系统运行/优化**
2. **新能源 + 储能**
3. **微电网/虚拟电厂**
4. **配电网 + 电动汽车**

原因很简单：公开测试系统多、软件成熟、纯计算就能做完整实验、AI 辅助实现效率高，而且容易把“问题—模型—实验—结论”串起来。

## 仿真当然算实验

科研中的 experiment 不等于本科实验课的“接线、示波器、台架”。

对计算型电气研究，常见实验包括：

- IEEE 14/30/33/39/69/118 节点算例
- 不同负荷/新能源渗透率场景
- 故障或参数扰动
- Monte Carlo 场景
- baseline 对比
- 敏感性分析
- 时域仿真

它们通常称为 **numerical experiments / simulation studies / case studies**。

## 怎么选第一个方向

问自己三个问题：

- 我更喜欢“系统层面的问题”还是“器件/控制器本身”？
- 我希望第一个项目尽量纯电脑完成吗？
- 我能否用一句话描述自己想研究的对象？

如果前两题偏系统和纯计算，直接从**电力系统 + 新能源/储能优化**开始通常最稳。
