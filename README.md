# Electrical Research Starter

面向电气工程科研新手的入门导航仓库。

目标不是“资源越多越好”，而是帮助你在 **10 分钟内知道先学什么、先跑什么、先做什么**，并在 8 周左右完成一次小型但完整的科研训练闭环。

## 适合谁

- 电气工程/电气工程及其自动化本科或刚毕业学生
- 想尝试电力系统、新能源、储能、智能电网、优化、控制等方向
- 还没有完整科研经历，希望先从仿真和计算实验开始
- 可以使用 AI 辅助编程、检索、调试和写作，但希望自己真正理解研究逻辑

## 第一次科研，不需要先做这些

- 不需要一上来联系几十个教授
- 不需要马上参加组会
- 不需要先读几十篇论文
- 不需要先给大型开源项目提 PR
- 不需要先把 Python/MATLAB 学到程序员水平

## 现在先做什么

**推荐第一条路线：电力系统 + 新能源/储能 + 仿真/优化。**

1. 先读 [研究方向地图](docs/01-research-map.md)，用 15 分钟选一个最感兴趣的方向。
2. 打开 [工具箱](docs/02-toolbox.md)，优先选择 **MATPOWER** 或 **pandapower**。
3. 跑通一个官方示例，不追求创新。
4. 按 [8 周路线图](ROADMAP.md) 完成一次“复现 → 小修改 → 比较 → 分析 → 报告”。

## 一个核心原则

> **AI 可以替你完成大量实现工作，但不能替你承担研究判断。**

你可以让 AI 写代码、查 API、画图、整理文献和润色英文；但你自己必须知道：研究问题是什么、模型假设是什么、实验为什么这样设计、结果是否可信、结论是否成立。

## 第一个成果应该长什么样

第一次科研不必执着于“立刻发论文”。一个合格的第一阶段成果至少包括：

- 一套你能解释的模型/代码
- 一组可复现的实验结果
- 一份说明方法、设置、结果和结论的短报告
- 一个整理清楚的 GitHub 仓库

如果之后有导师指导，再进一步决定是否扩展为会议论文或期刊论文。

---

本仓库默认以 **电气工程本身** 为主线，AI 仅作为可选方法和生产力工具，而不是强制研究方向。
